Why travelers trust Wayfarer over basic prompts

Most AI trip planners ping-pong across a city and treat hotel stays like daily attractions. We solved the 4 core pitfalls.

Neighborhood-First Clustering

Every day is organized strictly within a tight geographic radius, calculating actual walking & transit friction so you never waste hours commuting.

The Persistent Lodging Anchor

Accommodation is modeled as a persistent home base with morning departures and evening returns — completely solving the "Stay at Hotel A" flaw.

Live Weather-Driven Scheduling

16-day live weather forecasts directly shape activities: rainy mornings automatically shift to indoor museums, arcades, and sheltered markets.

Model Context Protocol (MCP)

Open industry standards allow you to export one-click RFC 5545 calendar feeds for Google/Apple Calendar and publication-grade vector PDF dossiers.

LangGraph 0.2+ Architecture

Autonomous Agents Working in Concert

Instead of brittle prompts, five specialized agents coordinate state, verify constraints, and pause for your approval.

Node 1: Research Agent ~1.2s Parallel I/O

Real-Time Live Web, Weather & Hybrid RAG

Gathers live context using Tavily, Open-Meteo forecasts, foreign exchange rates, and a 2,180+ passage ChromaDB vector store. Rainy forecasts automatically reshape the schedule to indoor cultural experiences.

web_search get_weather hybrid_rag get_exchange_rate
Node 2: Planner

Deterministic Budget & Spatial Clustered Days

Splits budget across Lodging, Food, Activities, and Transit with pure mathematical functions. Clusters daily activities within 15–20 min transit radii to eliminate cross-city fatigue.

0Hallucinated Math
Node 3: Human Gate interrupt() Primitive

Durable State Persistence Across the Pause

Execution safely pauses inside the graph via interrupt(). Resumes seamlessly via Command(resume={action, feedback}) with zero state loss, backed by SQLite checkpoints.

approve modify reject
Node 4: Finalize & MCP Model Context Protocol

Interactive Routing, Wikipedia Photos & MCP Export

Geocodes every stop via Photon, routes driving/walking legs via OSRM/OpenRouteService, resolves high-confidence landmark imagery, and invokes the Travel Concierge MCP server for calendar and PDF dossiers.
